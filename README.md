# C2O Recruitment Manager CLI

A terminal-based recruitment candidate tracker built with Python, Supabase (PostgreSQL), and the `rich` UI library.

---

## Features

- **Full Pipeline CRUD**: Add candidates, view real-time pipeline status, update candidate stage, and delete records.
- **Visual Terminal UI**: Color-coded badges for hiring stages (`applied`, `screening`, `interviewing`, `offered`, `rejected`) rendered using `rich`.
- **Candidate Profiles**: Dedicated card view showing full candidate details, role, and UTC application timestamp.
- **Pipeline Filtering**: Filter candidate views by hiring stage.
- **Case-Insensitive Search**: Query candidates across name, email, or role via Supabase PostgreSQL filters.
- **Pipeline Analytics**: High-level distribution metrics, candidate stage breakdown, and percentage calculations.
- **Data Portability**: Full CSV export and batch CSV import capabilities.

---

## Tech Stack

- **Language**: Python 3.10+
- **Database**: [Supabase](https://supabase.com/) (PostgreSQL)
- **Terminal UI**: [Rich](https://github.com/Textualize/rich)
- **Environment Management**: `python-dotenv`

---

## Supabase Schema

The application relies on a `candidates` table in the `public` schema:

```sql
create table public.candidates (
    id bigint generated by default as identity primary key,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    full_name text not null,
    email text not null,
    role text not null,
    status text not null default 'applied'::text
);
